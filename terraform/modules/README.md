# modules: shared OpenTofu modules

Reusable modules the deployment units compose: `proxmox-vm` and `talos-vm`
(virtual machines), `cloudflare-dns`, `gitlab-project`, `tailscale-tailnet`,
`authentik-app`, and the Okta set: `okta-app`, `okta-authenticator`,
`okta-network-zone`, `okta-policy-signon`.
