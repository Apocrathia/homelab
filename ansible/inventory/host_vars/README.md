# host_vars — per-host configuration

One YAML file per managed host. `game.yml` sets the kopia paths and the
nginx/acme_sh site values, `unifi-os.yml` the static VLAN layout and podman
prereqs, and `ians-gaming-pc.yml` its backup paths and Sunshine KMS opt-in.
