# roles: Ansible roles

One directory per role: `acme_sh`, `common`, `hardening`, `kopia`,
`nginx_site`, `ollama`, and `tailscale`. Each carries the standard layout it
needs (`defaults/`, `files/`, `handlers/`, `meta/`, `tasks/`, `templates/`);
the per-role README documents its variables and behavior.
