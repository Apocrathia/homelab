# OpenSSF Scorecard

[![OpenSSF Scorecard](https://img.shields.io/endpoint?url=https://apocrathia.gitlab.io/homelab/scorecard.json)](https://apocrathia.gitlab.io/homelab/scorecard-full.json)

Security health metrics for this repository, generated by [OpenSSF Scorecard](https://securityscorecards.dev/).

## What is Scorecard?

Scorecard assesses open source projects for security risks through automated checks. It evaluates:

- **Branch Protection** - Are branches protected from direct pushes?
- **Code Review** - Are changes reviewed before merging?
- **Dependency Updates** - Is there automated dependency management?
- **SAST** - Is static analysis running on commits?
- **Vulnerabilities** - Are there known unpatched vulnerabilities?
