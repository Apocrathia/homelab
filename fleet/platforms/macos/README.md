# macos — macOS Fleet assets

The fullest platform tree: `commands/`, `configuration-profiles/`,
`declaration-profiles/`, `enrollment-profiles/`, `policies/`, `reports/`,
`scripts/`, and `software/`. Policies carry the app-install checks and the
CIS macOS 26 assessment; configuration profiles carry the CIS benchmark
payloads.
