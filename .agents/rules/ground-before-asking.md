# Ground before asking

Before surfacing questions to the user: prove what you can from the data provided
(repos, docs, configs, patterns, the disk). Say what you don't know. Bring only
what's genuinely unanswered. Do not ask the human things you can concretely,
reliably, honestly answer yourself from the project's documented truth.

Pairs with `clarify-dont-guess.md`: that rule handles irreducible ambiguity;
this rule handles avoidable questions.
