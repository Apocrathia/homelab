# `reconcile-context`: context truth pass (skill)

`SKILL.md` defines reconciling `AGENTS.md` and `.agents/context/` against the
repo: fix broken links, catalog drift, and routing mismatches. `scripts/`
holds the link, discovery, and frontmatter checkers plus the harness-surface
sync, wired into the `context-links` pre-commit hook.
