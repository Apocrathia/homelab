# `a2a` — A2A client package

Single-module Python package (`__init__.py`, httpx-based) for the a2a skill:
`agents()` roster listing, `send()` / streaming to a named kagent agent, and
reply parsing. Broker URL and auth headers load from
`~/.prime/agent/mcp-secrets.json` (`a2a` key).
