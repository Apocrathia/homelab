# Overview

> Deliver event streams to the systems that need them.

Routing sends events to destinations, connects pipelines, and splits one stream across independent processing paths.

Learn how to [send data to destinations](https://docs.tenzir.com/guides/send-to-destinations), [split and merge streams](https://docs.tenzir.com/guides/split-and-merge-streams), [fan out with subpipelines](https://docs.tenzir.com/guides/fan-out-with-subpipelines), [load-balance pipelines](https://docs.tenzir.com/guides/load-balance-pipelines), and [expose pipeline data as a server](https://docs.tenzir.com/guides/expose-data-as-server).
