# Overview

> Diagnose compilation issues, pipeline failures, resource growth, and node connectivity.

Troubleshooting starts with the symptom you can observe, then narrows the problem to a pipeline, operator, or connection.

Use these guides to [debug unexpected field values](troubleshooting/debug-field-values.md), [inspect the compilation output](troubleshooting/inspect-compilation-output.md), [investigate slow pipelines](troubleshooting/investigate-slow-pipelines.md), trace [memory](troubleshooting/investigate-memory-growth.md) or [storage growth](troubleshooting/investigate-storage-growth.md), and [reconnect an offline node](troubleshooting/reconnect-an-offline-node.md).
