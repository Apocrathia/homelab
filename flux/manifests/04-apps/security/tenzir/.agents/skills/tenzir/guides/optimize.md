# Overview

> Reduce data volume and processing work in a pipeline.

Optimization removes events and fields that do not need to continue through a pipeline. Doing this early reduces processing, storage, and downstream costs.

Learn how to [filter and select data](https://docs.tenzir.com/guides/filter-and-select-data), [slice and sample streams](https://docs.tenzir.com/guides/slice-and-sample-data), and [deduplicate events](https://docs.tenzir.com/guides/deduplicate-events).
