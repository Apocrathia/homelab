# ocsf_type_name

> Returns the typename for a given typeuid.

Returns the `type_name` for a given `type_uid`.

```tql
ocsf_type_name(id:int) -> string
```

## Description

### `id: int`

The `type_uid` for which `type_name` should be returned.
