# Overview

> Limit sensitive-data exposure while preserving useful structure.

Protection limits sensitive-data exposure before events leave a trust boundary. Depending on the use case, you can anonymize values irreversibly, replace them with stable pseudonyms, or encrypt them for controlled recovery.

Our guide on [masking sensitive data](https://docs.tenzir.com/guides/mask-sensitive-data) covers redaction, hashing, pseudonymization, and prefix-preserving IP address encryption.

Our guide on [encrypting sensitive data](https://docs.tenzir.com/guides/encrypt-sensitive-data) covers reversible encryption: managing keys, encrypting and decrypting fields, keeping equal values comparable, preserving value formats, and encrypting with a public key so that only the holder of the private key can decrypt.
