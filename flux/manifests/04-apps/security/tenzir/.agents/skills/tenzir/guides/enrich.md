# Overview

> Add context that the original event does not contain.

Enrichment adds context such as asset ownership, threat intelligence, and model-generated labels to events as they pass through a pipeline.

Use [lookup tables](https://docs.tenzir.com/guides/use-lookup-tables), [asset inventory](https://docs.tenzir.com/guides/enrich-with-asset-inventory), [threat intelligence](https://docs.tenzir.com/guides/enrich-with-threat-intel), or [AI enrichment](https://docs.tenzir.com/guides/enrich-events-with-ai) to supply the context your downstream systems need.
