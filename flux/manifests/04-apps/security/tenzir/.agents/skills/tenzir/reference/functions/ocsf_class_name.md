# ocsf_class_name

> Returns the classname for a given classuid.

Returns the `class_name` for a given `class_uid`.

```tql
ocsf_class_uid(id:int) -> string
```

## Description

### `id: int`

The `class_uid` for which `class_name` should be returned.
