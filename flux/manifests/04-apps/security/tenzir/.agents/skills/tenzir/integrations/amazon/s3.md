# Amazon S3 integration

> Store, retrieve, and manage data objects in a scalable and durable cloud storage service.

[Amazon Simple Storage Service (S3)](https://aws.amazon.com/s3/) is an object storage service. Tenzir can treat it like a local filesystem to read and write files.

S3

Use [`from_s3`](https://tenzir.com/docs/reference/operators/from_s3.md) to read files from S3. It supports glob patterns, automatic format detection, and IAM role assumption. For writing, use [`to_s3`](https://tenzir.com/docs/reference/operators/to_s3.md) with a print operator.

Queryable tables instead of files?

To land events as open Iceberg tables on S3 rather than loose objects, the [`to_iceberg`](https://tenzir.com/docs/reference/operators/to_iceberg.md) operator writes to [Amazon S3 Tables](https://aws.amazon.com/s3/features/tables/) with `catalog_aws_service="s3tables"` and to Glue-cataloged tables in regular buckets. See the [Apache Iceberg](../iceberg.md) and [AWS Glue](glue.md) integrations.

## Configuration

See [AWS Authentication](../../reference/aws-authentication.md) for the available AWS authentication mechanisms.

## Examples

### Read from an S3 bucket

```tql
from_s3 "s3://my-bucket/path/to/file.json.gz"
```

### Read all JSON files from an S3 bucket

```tql
from_s3 "s3://my-bucket/logs/**.json"
```

To collect S3 object references from a message broker, see [Read from message brokers](../../guides/collect/read-from-message-brokers.md#fetch-data-referenced-in-messages).

### Write to an S3 bucket

```tql
from {foo: 42}
to_s3 "s3://my-bucket/path/to/file.json.gz" {
  write_json
  compress_gzip
}
```
