# OpenTAXII Grafana dashboard

Grafana dashboard for the OpenTAXII workload (kube-prometheus-stack plus
Alloy to Loki). `grafana.yaml` wraps `dashboard.json` into a
`GrafanaDashboard` resource (`opentaxii-workload`) in the Security
folder.
