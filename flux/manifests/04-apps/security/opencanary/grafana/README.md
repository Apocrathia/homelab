# OpenCanary Grafana dashboard

Grafana dashboard for OpenCanary honeypot logs (Alloy to Loki,
`{namespace="opencanary",container="opencanary"}`). `grafana.yaml` wraps
`dashboard.json` into a `GrafanaDashboard` resource (`opencanary-alerts`)
in the Security folder.
