# Skyscraper config

Skyscraper setup for ES-DE scraping: `config.ini` (metadata and
`gamelist.xml` only, no media downloads), `ensure-binary.sh` for the pinned
build, and `scrape.sh`, which injects the ScreenScraper credentials at
runtime.
