# ES-DE themes sync config

`sync-themes.sh` mirrors the ES-DE themes-list into
`Emulation/themes/<reponame>/` as full clones, since ES-DE rejects shallow
theme repos. Theme root and list repo are overridable via `THEMES_ROOT` and
`LIST_REPO`.
