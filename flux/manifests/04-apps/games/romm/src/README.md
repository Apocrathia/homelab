# ROMM import scripts

Host-side scripts that run on an operator machine with kubectl access.
`import-backfill.py` plans bounded-parallel ES-DE media backfill segments
for RomM; `import-segments.py` runs a segment in the romm container;
`enqueue-scan.py` and the shell scripts trigger library scans.
