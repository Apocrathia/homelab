# Meshtastic

Web application for monitoring Meshtastic mesh networks over IP using [MeshMonitor](https://github.com/Yeraze/meshmonitor).

## Overview

Connects to a Meshtastic device via TCP/IP and provides:

- Real-time node discovery and monitoring
- Message sending/receiving with threading and reactions
- Interactive map visualization
- Telemetry graphs and dashboards
- Device configuration interface
- Automation features (auto-announce, auto-respond, etc.)

## Configuration

### Required Configuration

1. **1Password Secrets**: Create a 1Password item at `vaults/Secrets/items/meshtastic-secrets` with:
   - `session-secret`: Random 32+ character string for session encryption
   - `oidc-client-id`: Authentik OIDC client ID (auto-generated by Authentik blueprint)
   - `oidc-client-secret`: Authentik OIDC client secret (auto-generated by Authentik blueprint)

### Optional Configuration

- **Virtual Node Server**: Enabled by default on port 4404, allows multiple mobile apps to connect
- **Local Auth**: Can be disabled via `DISABLE_LOCAL_AUTH` to force OIDC-only authentication
- **TLS**: Set `MESHTASTIC_USE_TLS=true` if your device requires encrypted connections
