# Prime Agent seed files

Seed data copied to `/opt/data/.prime/agent/` on the Prime Agent box on
first boot (delete from the PVC to re-seed). Holds `settings.json` (default
provider `litellm`, default model `kimi-k3-prime`, telemetry off) and the
bundled extensions under [extensions/](./extensions/): a2a, discord,
litellm, webui, activity-recap, name-sessions.
