# k8sgpt

K8sGPT deployment: HelmRelease, namespace, secret, and the `K8sGPT`
custom resource that configures AI-powered cluster analysis. The AI backend
routes through cluster LiteLLM (`glm-5.3-prime`) with an OpenAI-compatible
API key from the `k8sgpt-secrets` secret.
