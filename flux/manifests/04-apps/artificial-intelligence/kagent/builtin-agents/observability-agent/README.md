# observability-agent

Prometheus/Grafana monitoring, dashboards, and incidents. Binds `kagent-tool-server` (read-only k8s tools), `grafana-mcp` (standalone mcp-grafana server), and a `promql-agent` subAgent.

Vendored from the kagent 0.10.4 chart subchart; see the
[builtin-agents README](../README.md) for provenance and fidelity notes.
