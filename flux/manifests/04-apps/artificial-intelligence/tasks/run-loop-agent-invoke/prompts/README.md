# run-loop-agent-invoke prompts

Agent prompt for the constant-loop tick. `task.md` runs one `run-loop`
invocation (`mode=scout`) end-to-end: rank work debt-first across the
issue tiers, execute the lap, and stop. `continuation.md` handles context
rollover.
