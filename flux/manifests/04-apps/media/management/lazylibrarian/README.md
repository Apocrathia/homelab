# LazyLibrarian

Book and audiobook metadata management for digital libraries.

> **Navigation**: [← Back to Media README](../../README.md)

## Overview

LazyLibrarian follows authors and grabs metadata for digital reading content. Uses Goodreads, LibraryThing, and optionally Google Books for author and book information.

## Features

- Author tracking and book metadata lookup
- Automatic downloads via indexer integration
- Magazine and audiobook support
- Calibre database integration
- Notification support for new content

## Integration

- **Prowlarr**: Indexer sync for search providers
- **Download Clients**: qBittorrent/SABnzbd for acquisitions
- **Calibre**: Optional database integration for library management
