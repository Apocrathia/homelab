# uptime-robot-ip-sync source

Python source for the UniFi sync: `sync_uptime_robot_firewall_groups.py`
pulls Uptime Robot's published checker IP list and updates UniFi firewall
address groups over the UniFi OS session + CSRF flow. `env.example` lists
the required environment variables.
