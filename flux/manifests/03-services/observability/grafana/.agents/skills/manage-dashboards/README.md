# manage-dashboards — manage existing dashboards

Manages and inspects existing Grafana dashboards via gcx: list, search, audit
what a saved dashboard contains, versions, folders, resource-file pull/push, and
PNG snapshots. Entry point: [`SKILL.md`](./SKILL.md).
