# debug-with-grafana — debug with Grafana signals

Investigates application problems and incidents using Grafana metrics, logs, and
traces via gcx. Accepts alert payloads, dashboard links, and trace IDs; uses
qualified baselines and trace diff. Entry point: [`SKILL.md`](./SKILL.md).
