# Prometheus

Monitoring that sits beside kube-prometheus-stack: the snmp-exporter
HelmRelease in `prometheus-system`, its ServiceMonitor and 1Password-backed
auth secret, the per-target scrape config trees under `snmp/`, `etcd/`, and
`gaming-pc/`, and the CNPG backup alert rules in `cnpg/`.
