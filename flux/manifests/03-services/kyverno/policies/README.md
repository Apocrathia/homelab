# Kyverno Policies

Kyverno policy manifests: admission rules, a deployment-recreate rule for
MCPServers, the Docker Hub pull-secret sync, and the resource cleanup
policies. `kustomization.yaml` applies the active set; the cleanup entries
are commented out and kept for reference. The parent README documents each
policy.
