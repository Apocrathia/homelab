# Renovate Operator Config

The `homelab` RenovateJob: its schedule, the `Apocrathia/*` discovery filter,
the Renovate image, and registry credentials pulled from the operator's
1Password-backed secret. Split into its own Flux Kustomization because the
RenovateJob CRD arrives with the operator chart.
