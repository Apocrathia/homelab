# Tetragon Grafana Dashboard

The Tetragon install-overview dashboard (grafana.com id 25789) imported into
the Security folder. `grafana.yaml` is the GrafanaDashboard CR;
`kustomization.yaml` packages `dashboard.json` into the `tetragon-dashboard`
ConfigMap it points at.
